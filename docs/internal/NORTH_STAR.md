## 这项目是什么

BookScope 是一个**读懂难读长文档的 AI 引擎**：你丢一份难啃的长文档进去（一整本书——小说／论文／理论书，或一摞红头文件……），问它任何问题，它从原文里找答案给你，每条结论都标出处——**找不到原文支撑的，就不说**。

**引擎通用、场景具体**：底层一套「整份读一次出带证据的结构 + 查询时按问派生分析」的引擎；**书是第一个做透的场景**（也是验证锚），**红头文件（党政公文）是第二个垂直**（1.6）。

跟直接问 ChatGPT 的区别：ChatGPT 凭记忆答（可能编），BookScope 是真翻你这份文档答。

**服务谁**：任何要读懂一份难读长文档的人——小说家、研究者、深度读者，以及要自己看懂政策公文的普通人。作者本人是其中一个，不是唯一。**公开书／公文能被分析好，本身就证明它有用**，不用等谁的私人稿子写完。

**为什么做**：作者在写长篇网文，需要一个真读过稿子的助手；同时这是一份能发表的 AI 案例研究——开发过程本身是作品。

## 底线不能破（这几条改了就跑偏）

- **没有原文证据就不输出结论**——这是立身之本，破了就成了另一个会编的 ChatGPT
- **用户自带 API key（BYOK）**，项目不内置任何厂商的 key
- **普通电脑能跑**，不准依赖 GPU
- **国内 LLM 优先**，默认用 DeepSeek 最便宜的 `deepseek-v4-flash` 档——大多数人用便宜档，按便宜档调才贴近真实
- **不绑死某一家 AI**，换 provider 不用改核心代码
- **产出不准出现真名 / 公司名**（这是要公开的）
- 删库、强推这种危险操作，必须人动手
