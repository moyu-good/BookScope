## 告警分类说明

- **活跃告警**：AI 判断不了或已触发红色条件的事项，该方向工作暂停
- **需作者决策**：AI 提议方案但需作者取舍的事项，不一定阻塞但建议下次 session 处理
- **已解除**：历史记录，供回顾

## 告警条目格式

```
### [YYYY-MM-DD HH:MM] 简短主题

**类型**：红色告警 / 决策请求 / 方向漂移 / 预算越界 / 其他

**触发原因**：一句话说明

**建议处理**：AI 给出的建议

**阻塞的工作**：列出因此暂停的任务

**处理人**：作者（写入处理结论后移到已解除）
```
