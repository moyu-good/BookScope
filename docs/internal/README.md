# docs/internal — 项目内部档案

这里放 BookScope 的**内部运营文档**和**研究草稿**，不是给初次使用者看的。

初次上手请看：
- 仓库根 [README](../../README.md) —— 这是什么、怎么跑
- [用户手册](../USER_GUIDE.md) —— 13 个功能怎么用
- [架构总图](../ARCHITECTURE.md) + [ADR](../architecture-decisions/) —— 怎么搭的

## 这里都有什么

**运营手册**（BookScope 以「AI 团队 + 24/7 自主开发」模式运作，这些是它的规则与日志）：

- `NORTH_STAR.md` —— 项目定位与不变量
- `ROADMAP.md` —— 开发看板 / sprint 蓝图
- `WORKFLOW.md` · `AUTOLOOP.md` —— 工作手册 / 自主循环约定
- `DEPUTY_MANAGER.md` —— 主 Claude 的「副管理」姿态
- `FLAGS.md` · `NUMBERING.md` —— 告警清单 / 编号约定
- `STATE.md` —— 逐轮工作日志与交接

**研究档案**（草稿，**未定稿**）：

- `case-study/` —— 项目一路怎么演进的研究笔记 + 文章
- `experiments/` —— 跨题材 / 跨 provider 的实验设计与数据
- `research-notes/` —— 论文与方法笔记
- `design/` —— 各工作包（WP）的设计稿
- `audit/` · `build-log/` —— 审计与构建复盘

## 为什么公开它

完整的研究轨迹本身是这个项目的一部分价值，公开是为了透明。但请注意：**这里的研究文档是草稿，不代表定稿质量**；case-study 的定稿版本由作者本人润色后才会提到主线文档。内部黑话、过程细节难免，看个过程就好。
