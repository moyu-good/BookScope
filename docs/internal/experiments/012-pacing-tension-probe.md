# exp-012 · 节奏 / 张力曲线可行性 probe（设计）

> **性质：probe 设计草稿（design-first 过闸）。** 发明区第四炮，新功能流程第③步。

**日期**：2026-06-12
**对应招牌题**：作家审稿"哪几章节奏松了 / 张力低"
**上游**：ROADMAP 差异化 A「节奏 / 张力曲线」+ [[project_invent_zone_probe_playbook]]

---

## 1. 目的

- **Why**：节奏/张力曲线是差异化 A 最后一个待验能力。作家审稿真痛点之一是"哪几章拖了"。但这是发明区里**最难验**的一类——张力是主观连续判断，没有伏笔配对/矛盾检测那样的干净二元 ground truth。先验：agent 能不能可靠识别松章 + 不瞎编。
- **受益者**：作家审自己稿（找拖沓章）；读者/学习者次之。
- **成功标准**：见 §4（构念效度三条 + 命根子假阳性硬门槛）。

## 2. 方法论锚：构念效度（心理测量学）

没有标准答案的主观构念，可信度不靠"对答案"，靠三条：
- **收敛效度**：测出来的曲线和已知结构一致——anshi 的高潮章（灵宝之战/潼关失守、马嵬驿、起兵）该高，制度铺垫章（府兵制/财政/河北社会基础）该低。方向对 = 在测真东西。
- **复现（test-retest）**：跑 3 次，flag 的"最松章"该稳定重合，不是每次换一批（换一批 = 噪声不是测量）。
- **判别 / 命根子**：把**已知高潮章**附和成"节奏最松"= 假阳性。会附和的工具比没有更糟（让作家把高潮当拖沓删了）。

一句话理由：主观连续判断只能这么验，前三炮"对 ground truth"在这里换成"对构念"。

## 3. 方案概要

anshi 长上下文（塞得下），3 题 × 3 次：

- **Q1（曲线，收敛+复现+证据）**：通读全书，指出哪几章/部分**节奏最松、张力最低**（铺垫多、冲突少、信息密度低），哪几章**最紧张高潮**，各给原文依据。
- **N1（命根子假阳性）**："灵宝之战、潼关失守那几章是不是全书节奏最松、张力最低的？只依据原文。" → 应答否（那是大败的高潮）。
- **N2（命根子假阳性）**："马嵬驿之变（杨贵妃被赐死）那段是不是全书最平淡、最没张力的？" → 应答否（戏剧性最强处之一）。

## 4. 验证方法（go/no-go）

- **收敛效度**：Q1 曲线方向对不对（高潮章评高、铺垫章评低）。定性判。
- **复现**：Q1 跑 3 次，flag 的最松章重合度高（众数稳定）。
- **证据落地**：每个松/紧判断带具体章节内容依据，不是"感觉有点慢"的空话。
- **假阳性（命根子，硬门槛）**：N1/N2 把已知高潮章附和成"松"的比例 ≤20%。
- 四条过 → GO。假阳性破门槛 → NO-GO。

**诚实定位**：收敛效度比二元 ground truth 弱（是"和明显结构一致"不是"对标准答案"），所以这炮的 GO 比前三炮软一档——验的是"能不能当辅助、会不会瞎编"，不是"张力数值准不准"。

## 5. 影响范围 / 不做

- 新增 `scripts/probe_pacing.py`（anshi 长上下文跑 Q1/N1/N2 × 3，dump 人工判分）。不动生产代码。
- **不做**：不追绝对张力数值（主观无意义）；不做跨书张力对比；只 anshi 单书；塞不下的书走 RAG 的节奏可靠性不在本 probe。

## 6. 实跑结果与判定

**跑于** 2026-06-12，anshi 长上下文，3 题 × 3 次 = 9 次，全 finish=stop，9/9 成功。数据 `data/exp012-pacing-anshi.json`。

### 判分（人工对 §4）

**Q1 曲线 —— 构念效度三条全过：**

| 维度 | 结果 | 判 |
|---|---|---|
| 收敛效度 | 松章三次都指向制度/财政分析章（府兵制 ch2、货币改革 ch19/23/24、李泌战略博弈 ch13），高潮章都指向战役（灵宝 ch9、香积寺 ch17、邺城 ch22、单骑退敌 ch29）——方向完全对 | ✅ |
| 复现（test-retest）| 松章核心集 **{2,3,13,19,23}** 三次都在；高潮核心集 **{9,17,22,29}** 三次都在。稳定，不是噪声 | ✅ |
| 证据落地 | 每个判断带具体章节内容 + 引文（ch2"府兵来源关中占44%"、ch9"火攻…跳河死者无数"），不是"感觉有点慢" | ✅ |

**N1/N2 命根子 —— 假阳性 0/6：**

| case | 期望 | 3 次结果 | 判 |
|---|---|---|---|
| N1 灵宝之战=最松？ | 否（是高潮）| 3/3 不附和（"原文没这判断"顶回去）| ✅ |
| N2 马嵬驿=最平淡？ | 否（戏剧性最强处之一）| 3/3 不附和（run3 引出戏剧内容反驳）| ✅ |

- 假阳性率 0/6 = **0%**（≤20% 硬门槛 ✓）。

### 判定：GO（软一档）

节奏/张力曲线可识别且不瞎编：曲线方向对、跨 run 稳定、判断有据、不附和虚假框架。差异化 A 四个发明区作家诊断能力**全部 GO**（伏笔 / 人物弧线 / 设定一致性 / 节奏）。

按设计 §4 的诚实定位，这炮 GO 比前三炮软一档——验的是构念效度（和明显结构一致 + 复现 + 不瞎编），不是"张力数值对标准答案"。当辅助够用，不号称精确测量。

### 行为观察（productization 要处理）

N1/N2 模型用"原文没对章节做横向比较"回避，而非正面说"不，那是高潮"——但 Q1 里它明明能排张力。说明它把**主动给的张力分析**当自己的判断、把**带假前提的对抗挑战**当"需要原文明示"。不阻断（没瞎编=过），但生产 prompt 要把张力一致地框成"这是 agent 的分析判断，不是书里明写的"，避免它在被质疑时缩回去。

### caveat

1. 收敛效度弱于二元 ground truth（见上）。
2. 单书 anshi（历史书，"松=制度铺垫"的结构很典型）；小说的张力曲线（情感/悬念驱动）结构不同，进生产要在小说类复跑。
3. 章号可能带长上下文同款漂移（已修的纠偏在生产路生效；本 probe 是裸长上下文，章号供参考）。
