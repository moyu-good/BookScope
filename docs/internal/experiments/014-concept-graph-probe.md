# exp-014 · 概念关系图可行性 probe（设计）

> **性质：probe 设计草稿（design-first 过闸）。** 发明区第六炮、学习者受众。人物图的跨题材投影。

**日期**：2026-06-12
**对应招牌**：学习者"这本理论书的概念怎么勾连" + NORTH_STAR「跨题材分析单位自适应」
**上游**：人物关系图（exp-013 GO + 功能已建）+ [[project_invent_zone_probe_playbook]]

---

## 1. 目的

- **Why**：概念关系图 = 人物关系图的跨题材投影（分析单位从"人物"换成"概念"），服务拿理论书学东西的学习者，兑现 NORTH_STAR「人物图和概念图本是同一能力的两个题材投影」。**新未知点**：概念比人名模糊——人名是确定的命名实体，概念边界虚、同一概念表述多样、概念间关系更抽象。所以不能直接套人物图，要 probe 验抽取在理论书上还成不成立。
- **受益者**：学习者（拿理论书学手艺/理论）；研究者。
- **成功标准**：见 §4。

## 2. 方法论锚

- **发明区 probe playbook（本人沉淀）**：正例(收敛)+命根子(假阳性)+每边证据+复现+3次。
- **命根子主控 = 每边证据率**：概念关系图也是一堆带证据的边——编的概念关系，evidence 校验不过（同 exp-013 anshi 的 22/22 逻辑）。加 2 道明显跨域不存在关系的 N 题兜底。

一句话：概念图就是把"边粒度证据校验"从人物关系搬到概念关系，验"概念这种模糊单位"上还稳不稳。

## 3. 方案概要

zhinei（《制内市场》理论书，塞得下）长上下文，3 题 × 3 次：

- **Q1（抽概念图，收敛+证据+复现）**：梳理这本书的核心概念之间的关系——哪些概念、概念间什么关系（定义/包含/对立/因果/递进/支撑等），**每条关系给原文依据**。
- **N1（命根子，明显跨域不存在）**："书里有没有直接论证'制内市场'和'量子纠缠'两个概念的关系？只依据原文。" → 应答没有，不编。
- **N2（命根子，明显跨域不存在）**："书里有没有把核心论点和'达尔文进化论'联系起来论证？只依据原文。" → 应答没有。

判分参照（zhinei 已知）：核心概念是"制内市场"，应处于中心、与"国家/政府""市场""产权/国企"等有论证关系（exp-009 验过 agent 能讲清这本书的核心论点链）。

## 4. 验证方法（go/no-go）

- **收敛效度**：Q1 抽出的概念网以"制内市场"为中心、连到国家/市场等核心概念，关系类型合理。
- **每边证据率（命根子主控）**：抽出的概念关系带原文依据并校验命中的比例——高 = 不编（参照 exp-013 anshi 22/22）。
- **复现**：核心概念集跨 3 run 稳定。
- **假阳性（N 题，硬门槛）**：N1/N2 编造跨域不存在关系的比例 ≤20%。
- 四条过 → GO（GO 后建设 = 把人物图功能泛化成"分析单位=人物|概念"，小改）。

## 5. 影响范围 / 不做

- 新增 `scripts/probe_concept_graph.py`（zhinei 长上下文跑 Q1/N1/N2 × 3，dump 人工判分；复用 probe_character_graph 形态、max_tokens 8000）。不动生产代码。
- **不做**：不建概念图前端（GO 后泛化人物图功能）；不跑诗歌/其它题材（留后续）；只 zhinei 单书。

## 6. 实跑结果与判定

**跑于** 2026-06-12，zhinei 长上下文，3 题 × 3 次，全 finish=stop，9/9 成功。数据 `data/exp014-concept-graph-zhinei.json`。

### 判分（人工对 §4）

| 维度 | 结果 | 判 |
|---|---|---|
| 收敛效度 | 三次都以**制内市场为中心**，连到 场内国家(对立)/不对称均衡(机制)/三层市场(包含)/国家主导(核心)/儒法两种市场(思想源)/动员经济(前身)/地缘政治(因果)/家庭自留地(类比国企/央企)——完全贴合书的真实论证结构 | ✅ |
| 每边证据 | 每条概念关系带引文 + 章节（与 exp-009 验过的核心论点链一致）；生产路会过边粒度 verify_citations（同人物图 22/22） | ✅ |
| 复现 | 核心概念集 + 关系类型三次稳定 | ✅ |
| 假阳性（N 题，命根子）| N1（量子纠缠）3/3"没有"；N2（达尔文）3/3"没有"，**且主动指出书里确有"社会达尔文主义"（严复）但正确区分"作背景提及"vs"论证核心"** | ✅ 0/6 |

### 判定：GO

概念关系图（学习者受众、人物图的跨题材投影）可行。担心的"概念比人名模糊"在这本书上没成问题——**理论书把概念显式定义了（制内市场/场内国家是造的术语带定义），抽取反而比模糊实体清晰**。N2 还暴露了 agent 的高水平诚实：找到边缘提及（社会达尔文主义）却不overclaim 成核心论证。

### 关键收获 + 下一步

- **跨题材投影成立**：同一长上下文抽取机制，把"分析单位"从人物换成概念就能跑——兑现 NORTH_STAR「人物图和概念图是同一能力的两个题材投影」。
- **建设 = 把人物图功能泛化成"分析单位 = 人物 | 概念"**（小改：抽取 prompt 按 unit 切、端点加 unit 参数、FE 复用同一个图组件）。
- **caveat**：① 显式定义术语的理论书最友好；概念隐含的随笔/散文类更难，建设后需复跑。② 单书 zhinei。③ 关系类型（定义/包含/对立/因果）比人物关系更抽象，FE 边标签要可读。
