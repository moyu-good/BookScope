# WP-ui-design-language · BookScope 界面设计语言（作者已认可，2026-06-15）

> **性质：设计语言规范（一等可存内容）。作者 2026-06-15 看草图认可"数字善本案头 · 评点钤印"方向后定。** 所有前端改动以此为准；后续 session 照此搭，别又回到通用 SaaS 样子。

## 一句话定位

BookScope 的界面是**数字善本案头 / 评点本**，不是通用工作台。它服务"深读一本书、每个结论钉在原文上"，所以界面母题取自**古籍评点 · 案头批注 · 钤印鉴定**——全世界没人拿这套做软件，这就是不同质化的来源。

## 骨架：app-shell（作者认可的结构）

不再单列往下滚。**左栏常驻 + 宽主画布**：

- **左栏（函套 / 书脊气质）**：藏书印（朱砂"鑒"，略旋转）+ "书鉴"字号；"案上"当前书（书名宋体 + 作者字数）；模式导航（问书 / 人物关系 / 时间线 / 节奏 / 一致性 / 概念图，活动项朱砂左边线 + 朱砂淡底）；底部书库 + 设置齿轮。暖调（比纸略黄），右边线用朱砂淡线，不是通用灰侧栏。
- **主画布**：一次只显示一件事，留白足、是绝对主角。功能多 = 左栏多一项，**绝不往下堆一屏**。
- **响应式**：手机端左栏收成抽屉（汉堡触发）。

## 魂：四个独有 primitive（这是不撞脸的关键，必须保留）

1. **钤印核验**——核验过的原文，角上盖一枚朱砂「鉴」小印（方形、1.5px 朱砂边、朱砂淡底、略旋转 -7deg）。**印章 = 证据核验的视觉语言**（"逐字核验过，盖章为证"），不是装饰。这是把 BookScope 的立身之本变成界面动作。`match_type=quote/paraphrase`→盖印；`none`→不盖。
2. **评点排版**——答案排成"评点本"：**朱批**（AI 的判断，朱砂小标 + 宋体正文）+ **原文为证**（引证卡，带章号 + 钤印）。像金圣叹评点本，不是 SaaS 问答气泡。
3. **函套书脊侧栏**——见上，暖调 + 藏书印，有"书"的实体感。
4. **古籍细节·克制**——朱墨双色；版心式朱砂短线（标题下一道 ~54px 朱砂线）；❡/鱼尾点到为止；宋体当主角。**高级 = 克制**，绝不堆满古风元素（堆满就 low 了）。

## 既定基础（前几版已定，继续用）

- **色**：`--color-seal` 朱砂红 oklch(50% 0.18 30)、`--color-ink` 水墨、`--color-paper` 宣纸暖白、`--color-paper-raised/sunken`、`--color-seal-soft`、`--color-rule`。
- **字**：`--font-display` 宋体（标题/正文主角）、`--font-body` 黑体（UI）。
- **动效**：`reveal-up`（淡入上浮）/`stagger`（错落）/`seal-in`（盖章弹入）；`--shadow-soft/raised`（纸上叠纸柔影）；`:focus-visible` 朱砂焦点环；`prefers-reduced-motion` 全尊重。

## 反模式（命中即不合格）

- 通用灰侧栏 / Linear-Notion 撞脸样；单列往下堆一屏；朱砂当四条大分隔线滥用；emoji 当图标（用 SVG / Tabler）；堆满古风元素（鱼尾/云纹/边框糊一脸）；印章当纯装饰（必须挂在"核验"语义上）。
